# FAITH

**Seamlessly Connect with Sanatan Dharma.**

FAITH is an open-source application designed exclusively for the Hindu community. It transforms unrefined daily routines into moments of devotion by providing instant access to the Bhagavad Gita, daily shlokas, aartis, and vrat kathas in a modern, ad-free environment. 

> **100% Ad-Free & Offline.** No distractions, no tracking, and fully accessible without an internet connection. All core texts are stored locally for uninterrupted spiritual practice.

`Node.js` `Tailwind CSS` `Lovable` `Open Source`

---

## ✨ Features

### 📖 Sacred Texts & Resources

| Resource | Purpose |
| :--- | :--- |
| **Bhagavad Gita** | Full chapter-by-chapter access providing deep philosophical insights with accurate translations. |
| **Daily Shlokas** | Curated verses formatted for quick reading to begin your day with focused devotion. |
| **Aartis** | A comprehensive, easily navigable library of aartis for various deities and daily pujas. |
| **Vrat Kathas** | Detailed stories, historical context, and guidelines for traditional fasting days and rituals. |

### 🧠 Accessibility & Experience

One-click features and design modifiers that enhance your reading experience:

* **Bilingual Toggle** — Switch seamlessly between English and Hindi translations.
* **Offline-First Architecture** — Access your spiritual library anywhere, even on a commute or in a temple with poor reception.
* **Distraction-Free UI** — Eliminates digital clutter in favour of clean typography and a modern aesthetic.
* **Zero-Yapping** — Straight to the texts, zero conversational filler or unnecessary pop-ups.

## 🛠 Development

This project is actively built and maintained using [Lovable](https://lovable.dev). Every change made in the Lovable editor is committed straight to this repository, ensuring full code ownership.

Prefer working locally? You will need Node.js and npm — install with nvm.

```bash
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
